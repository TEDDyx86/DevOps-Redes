# PostgreSQL Implementation Plan

**Goal:** Monitorar PostgreSQL real com dashboard, alertas e recuperação sem derrubar a plataforma.

**Architecture:** Coletor SQL assíncrono e gerador de carga independentes; Prometheus persiste as métricas e FastAPI fornece o detalhe ao React. Incidentes ficam no armazenamento existente.

**Tech Stack:** PostgreSQL 17.11, psycopg 3, Prometheus/Alertmanager, FastAPI, React.

## Restrições

- Preservar o serviço HTTP e seu contrato.
- Não expor porta SQL nem credenciais ao frontend.
- QPS do laboratório e transações/s são métricas diferentes.
- Falha do banco não derruba a API nem o registro de incidentes.
