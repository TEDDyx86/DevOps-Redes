# Autenticação Implementation Plan

**Goal:** login local com sessão revogável, eventos e detecção de falhas repetidas.
**Architecture:** scrypt + sessões SQLite independentes do PostgreSQL monitorado. Middleware protege dados e controles. React usa gate de sessão; Prometheus alerta sobre falhas registradas.
**Tech Stack:** Python hashlib/sqlite3, FastAPI, React, Prometheus/Alertmanager.

## Restrições

Executar sequencialmente. Não interromper sondas/scrape/webhook. Não versionar credenciais. Manter `.env` existente; configurações repetidas preservam senha e hash. Requisitos em `docs/superpowers/specs/2026-10-28-auth-design.md`.
