# DNS Implementation Plan

**Goal:** Monitorar resolução DNS real em UDP/TCP, com métricas nativas, alertas e recuperação.

**Architecture:** CoreDNS com zona local; sonda dnspython assíncrona independente; Prometheus coleta sonda e servidor; FastAPI oferece o detalhe ao React.

**Tech Stack:** CoreDNS 1.15.0, dnspython, FastAPI, Prometheus/Alertmanager, React.

## Restrições

- Preservar contratos HTTP/SQL e o armazenamento independente de incidentes.
- Não alterar o DNS do host nem publicar a porta do servidor.
- Distinguir NXDOMAIN de falha do servidor e ausência de métricas de falha de resolução.
- Não usar dados sintéticos nos gráficos.
