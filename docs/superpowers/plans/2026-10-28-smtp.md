# SMTP Implementation Plan

**Goal:** completar o quarto protocolo com entrega local, fila persistente e monitoramento real.

**Architecture:** aiosmtpd aceita mensagens para SQLite; worker entrega via smtplib ao Mailpit exclusivo. API coleta sonda SMTP e consulta métricas no Prometheus. React segue os componentes existentes.

**Tech Stack:** Python, aiosmtpd, SQLite, FastAPI, Prometheus, React, Docker Compose.

## Restrições

Executar sequencialmente neste workspace. Preservar os três serviços existentes e o canal independente de alertas. Não enviar correio externo. Seguir o contrato em `docs/superpowers/specs/2026-10-28-smtp-design.md`.
