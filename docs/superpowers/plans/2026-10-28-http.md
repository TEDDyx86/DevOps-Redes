# Primeiro ciclo HTTP Implementation Plan

> Execução inline nesta conversa, conforme autorização do usuário para começar a construir. Revisão independente ao concluir a etapa.

**Goal:** Executar um ciclo HTTP real de coleta, visualização, incidente, e-mail e recuperação.

**Architecture:** API FastAPI consulta séries do Prometheus, executa sondas e persiste eventos recebidos do Alertmanager. React consome apenas a API; um serviço de demonstração separado recebe tráfego e permite falhas controladas.

**Tech Stack:** Python/FastAPI/httpx/prometheus-client, SQLite, React/TypeScript/Vite/Recharts, Prometheus, Alertmanager, Mailpit, Docker Compose.

## Global Constraints

- Português na interface; funcionamento local em Windows e via containers Linux.
- Sem dados sintéticos apresentados como coleta real.
- Sem dados disponíveis ou coleta desatualizada não pode resultar em estado OK.
- Não enviar e-mails a terceiros: destinatário local de testes.
- Etapa HTTP apenas; demais serviços e segurança registrados no roadmap.
